# rpg-bonificaciones

Simulación técnica en RPG ILE para aplicar bonificaciones del 10% en pólizas tipo A. Proyecto orientado a entrevistas en banca y seguros, con documentación funcional, pruebas en Excel y lógica compilable en IBM i.

## 📌 Objetivos
- Simular un cambio normativo vigente a partir del 1 de noviembre.
- Aplicar lógica condicional en RPG ILE.
- Documentar el proceso técnico y funcional.

## 📂 Estructura del repositorio
- `/src`: Código fuente en RPG ILE (`BONIFILE.rpgle`)
- `/docs`: Documentación funcional en Word
- `/tests`: Casos de prueba en Excel

## 🛠️ Tecnologías utilizadas
- RPG ILE / Free
- IBM i / AS400
- Markdown para documentación
- GitHub Projects para gestión visual
